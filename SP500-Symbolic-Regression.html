S&P 500 Symbolic Regression

Using symbolic regression (PySR) to search for interpretable equations that predict S&P 500 forward returns, and testing whether they find structure beyond simple momentum.

The question

Symbolic regression searches for a closed-form equation rather than fitting a black box. A common critique is that, when run on price data alone, it mostly rediscovers momentum. This project feeds it a mixed feature set (trend, volatility, liquidity and mean-reversion) and asks whether the equations it finds actually combine different kinds of signal, for example an RSI term that only matters in a particular momentum regime. The goal is understanding what the model finds, not chasing alpha.

Data and features

Daily OHLCV data for 501 S&P 500 tickers from 2015 to 2025, roughly 1.3 million rows after cleaning, cached to Parquet. Features are computed per ticker with grouped operations and then z-scored cross-sectionally within each day:

  • Momentum (backward-looking return over 21 days)
  • Volatility (rolling standard deviation of daily returns)
  • Volume ratio (volume relative to its rolling mean)
  • RSI (14-day, built from rolling average gains and losses)

The target is the forward return, built with a forward shift so that no feature can see the future.

Data quality

Real market data is messy. I wrote a cleaning step that trims stale pre-listing and SPAC history for affected tickers and removes zero-volume rows, then checked the effect on row counts at every stage. Range checks on the features, such as RSI staying within 0 to 100, caught a sign bug in my own loss calculation early.

Evaluation plan

  • Time-based split: train through 2021, validate 2022–2023, test 2024–2025, with a 5-day embargo to avoid label leakage
  • Baselines: linear model, XGBoost and a small MLP
  • Metrics: information coefficient (IC) and a long-short backtest
  • Analysis of which feature types the discovered equations actually combine

Status

In progress. The data layer, cleaning and feature pipeline are built and tested on the full universe. Next up are final data validation, the time split, baselines and the PySR runs. I am building the core logic by hand so I understand the mechanics (lookahead bias, grouped rolling windows, cross-sectional normalization).

Tools

Python, pandas, NumPy, PySR, Parquet, Jupyter
