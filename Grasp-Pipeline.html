Robot Grasp Pipeline

A modular grasp-synthesis pipeline for a 6-axis robot arm in MuJoCo, combining classical grasp sampling with a learned residual policy. Team project, summer 2026.

Overview

Our four-person team built a pipeline that takes a CAD model of an object, proposes grasps for it, and executes them with a 6-axis arm in simulation. I worked on pose sensitivity tuning, training on randomized object placements, and object manipulation.

Pipeline

  • Grasp candidates: antipodal sampling generates 6-DoF grasp candidates directly from CAD meshes using trimesh. Thin, blade-shaped objects needed special-case handling.
  • Control: a classical impedance controller handles contact so the arm stays compliant while grasping.
  • Learning: a TD3-based residual reinforcement learning policy corrects the classical grasp rather than replacing it.

Result

The test task was picking up a fan blade in random poses. Grasp success improved from 56% to 85% as the pipeline came together. The project was not fully finished by the end of the summer, but the modular structure meant each stage could be tested on its own.

What I took from it

Where to spend learning and where to rely on classical methods, how sensitive a policy is to object pose, and how much of a robotics ML project is evaluation and iteration rather than the model itself.

Tools

Python, MuJoCo, trimesh, reinforcement learning (TD3)
