Course Deadline App

An app that reads course emails and announcements and turns them into deadlines, using cheap local ML models first and an AI model only for the cases they are unsure about.

The problem

Important deadlines are buried in announcements and emails across many courses. Students shouldn't have to copy them into a calendar by hand, and the tool should not depend on anyone manually entering data.

Approach

  • Local models first: lightweight ML models handle the common cases to keep cost and latency low
  • AI fallback for uncertainty: when the local model is not confident, the message is sent to an AI model to check
  • Constraints I set: no scraping, no paid API keys, no manual data entry, and it should be useful beyond just me

Status

Early stage, started in October 2026 as my CS 124 independent project. It is a pivot from an earlier study-spot finder (Open Seat) I built during the course's prototype activities. The first version will work for a single user.
